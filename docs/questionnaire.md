# SignBridge — Questionnaire used (Google Form)

Form: "User Survey on SignBridge: Indian Sign Language Detection". Responses: `survey_responses.csv`, tabulated in `interviews.md`, analysed in report Section 4.

1. Which category best describes you?
2. How familiar are you with Indian Sign Language (ISL)?
3. How often do you interact with people who use sign language?
4. How difficult do you think communication can be between an ISL user and someone who does not know ISL?
5. Have you ever used a sign language recognition or translation application?
6. How useful would a system that recognises ISL signs through a camera and displays the corresponding words be?
7. Which output would be most useful to you?
8. Which feature would be most important in such an application?
9. What should the application do when it is unsure about a sign?
10. How likely would you be to use or recommend such a system if it worked reliably?
